# ALMA AI 助手 - 快速上手指南

## 🚀 5分钟快速启动

### 1. 环境准备

```bash
# 确保 Python 3.8+ 已安装
python --version

# 进入项目目录
cd /Users/chenjiamin/python/ALMA/web

# 安装依赖
pip install -r requirements.txt
```

### 2. 数据库配置

项目已预配置数据库连接，如需修改请编辑 `config.json`：

```json
{
  "database": {
    "host": "101.34.214.7",
    "port": 3306,
    "database": "alma_db",
    "user": "root",
    "password": "wenhantop123"
  }
}
```

### 3. 初始化数据库

```bash
# 一键初始化数据库和表结构
python init_database_sqlmodel.py
```

### 4. 启动应用

```bash
# 启动统一应用（默认端口 8501）
python start.py

# 指定端口启动
python start.py -p 8502

# 初始化数据库（如果还没有初始化）
python start.py -i

# 查看帮助信息
python start.py -h
```

### 5. 访问应用

- **统一应用**: http://localhost:8501（或您指定的端口）
- **登录方式**：
  - 👤 **用户登录**：输入用户名和密码
  - 🔧 **管理员登录**：输入管理员密码（默认：admin123456）

## 👥 用户使用流程

### 1. 用户注册

1. 访问统一应用 (http://localhost:8501)
2. 在登录页面选择"👤 用户登录"
3. 点击"注册"标签页
4. 输入用户名、密码、确认密码
5. 输入邀请码（如：ALMA2024001）
6. 点击"注册"按钮

### 2. 用户登录

1. 在登录页面选择"👤 用户登录"
2. 在"登录"标签页输入用户名和密码
3. 点击"登录"按钮
4. 成功登录后进入聊天界面

### 3. 开始聊天

1. 选择 AI 工作流（如：通用助手）
2. 在输入框中输入问题
3. 按回车或点击发送
4. 等待 AI 回复

### 4. 管理对话

- **新建对话**: 点击"新建对话"按钮
- **重命名对话**: 点击对话名称进行重命名
- **删除对话**: 点击对话右侧的删除按钮
- **切换对话**: 点击左侧对话列表中的对话

### 5. 文件上传

1. 在聊天界面点击"文件上传"按钮
2. 选择要上传的文件
3. 等待管理员审批
4. 审批通过后文件可用于 AI 分析

## 🚀 生产部署

### 1. 环境配置

```bash
# 设置环境变量
export STREAMLIT_SERVER_PORT=8501
export STREAMLIT_SERVER_ADDRESS=0.0.0.0

# 使用 systemd 管理服务
sudo systemctl enable alma-ai
sudo systemctl start alma-ai
```

### 2. 反向代理

```nginx
# Nginx 配置示例
server {
    listen 80;
    server_name your-domain.com;
    
    location / {
        proxy_pass http://localhost:8501;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3. 监控告警

```bash
# 设置健康检查
curl -f http://localhost:8501/health || echo "服务异常"

# 设置自动重启
while true; do
    if ! curl -f http://localhost:8501/health; then
        systemctl restart alma-ai
    fi
    sleep 60
done
```

## 🆘 故障排除

### 常见错误及解决方案

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `No module named 'mysql'` | 缺少数据库驱动 | `pip install pymysql` |
| `Can't connect to MySQL server` | 数据库连接失败 | 检查网络和配置 |
| `Unknown database 'alma_db'` | 数据库不存在 | 运行 `python init_database_sqlmodel.py` |
| `Port 8501 is already in use` | 端口被占用 | 终止占用进程或更换端口 |
| `Table 'user' is already defined` | 表重复定义 | 重启应用或检查代码 |
