# ALMA 项目说明

## 📋 核心文件说明

### 🔧 核心代码
- `models.py` - SQLModel 数据模型定义
- `auth.py` - 用户认证系统
- `backend.py` - Dify 工作流连接
- `front.py` - 用户前端界面
- `manager_front.py` - 管理员前端界面

### ⚙️ 配置和工具
- `config.json` - 主配置文件
- `config_local.json` - 本地配置模板
- `init_database_sqlmodel.py` - 数据库初始化
- `start.py` - 启动脚本
- `requirements.txt` - 依赖包列表

### 📁 数据目录
- `uploads/` - 文件上传存储目录

## 🚀 使用流程

1. **安装依赖**: `pip install -r requirements.txt`
2. **配置数据库**: 修改 `config.json`
3. **初始化数据库**: `python init_database_sqlmodel.py`
4. **启动应用**: 
   - `python start.py -u` (用户前端)
   - `python start.py -m` (管理员前端)
   - `python start.py -u -m` (同时启动两个前端)
   - `python start_both.py` (同时启动两个前端)
